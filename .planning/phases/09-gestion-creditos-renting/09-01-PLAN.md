4. LEDGER INMUTABLE: `historial_auditoria` append-only con `add()`.
   PROHIBIDO `batch.set()` en el ledger.
5. TAXONOMÍA: todo bajo `/admin/creditos/...` heredando el guard de `admin/layout.tsx`.

## Code Patterns (Model Resilience)

- `src/types/index.ts` — estilo de interfaces con `Timestamp` de `firebase/firestore`;
  snake_case para campos de negocio.
- `src/types/financial.ts` — uniones literales de dominio.
- `src/app/admin/config/page.tsx:45` — `{ id: d.id, ...d.data() }`: el docId NO
  pertenece a las interfaces; se adjunta en lectura.

## Conventions

- **NAMING LOCK:** prohibido renombrar/inventar colecciones o llaves del Documento.
- `historial_auditoria` es standalone (sin `updated_at`, sin `activo`): append-only.
- `clientes_credito.fecha_registro` es el SSOT de registro; `created_at` NO aplica
  ahí (prohibida doble fuente de verdad); `updated_at` sí aplica.
- Tipos numéricos: dinero = Float (double); contadores = Int64. Ver task 4.
