# Plan 9-6: UI Módulos 2–5 + E2E en Beta

## Objective

Crear las rutas UI de los Módulos 2–5 del Documento de Negocio y cerrar con verificación
E2E sobre datos reales en `https://tiendalasmotos-beta.web.app`.

- Módulo 2 — Terminal de Cobro (`/admin/creditos/pagos`)
- Módulo 3 — Cierre de Caja (`/admin/creditos/remisiones`)
- Módulo 4 — Rendimiento e Inversores (`/admin/creditos/inversores`)
- Módulo 5 — Auditoría (`/admin/creditos/auditoria`, estrictamente read-only)

## Code Patterns (Model Resilience)

- `src/app/admin/creditos/page.tsx` (09-05) — patrón listado + modal + Burst Mitigation +
  Faraday Cage + `useAuth()` → Server Actions. REPLICAR.
- `src/app/admin/creditos/financiero-actions.ts` (09-04) — `createPagoYMulta`,
  `generarCierreCaja`, `aprobarRemision`, `createPagoInversor`.
- `src/lib/actions/creditos-calc.ts` (09-01) — `calcularMoraRenting`, `calcularComision`.
- `.agent/rules/desarrollobeta.md` — única URL de validación: `https://tiendalasmotos-beta.web.app`.
- `.agent/rules/prohibiciondereportesbasadosendatossimulados.md` — cierre solo con datos reales.

## Conventions

- Módulo 2: búsqueda por `vehiculo.placa` (query `where('vehiculo.placa','==',placa)`) o
  por documento (cedula → `clientes_credito` → `creditos.id_cliente`); al registrar,
  mostrar el desglose `valor_comision`/`valor_neto_empresa` que devuelve el servidor;
  `registrado_por` se inyecta en servidor (la UI no lo envía).
- Módulo 3: vista cobrador muestra la suma acumulada de `valor_neto_empresa` del día y el
  botón "Generar Cierre de Caja" (crea `pendiente`); vista admin lista `pendiente` y
  aprueba → `recibido`.
- Módulo 4: dashboard por inversor sumando `valor_neto_empresa` de los `pagos_y_multas`
  de créditos cuyo `asignaciones.uid_inversor === inversor`; formulario de giro →
  `createPagoInversor` (salida en `pagos_inversores`).
- Módulo 5: ledger read-only con filtros y diff expandible; PROHIBIDO cualquier
  `addDoc/updateDoc/deleteDoc/setDoc` en el archivo.
- C4 heredado (Burst Mitigation, Faraday Cage, tolerancia legacy) en todos los formularios.
