# Plan 9-5: Sidebar + rutas + UI Módulo 1 (Gestión de Contratos)

## Objective

Inyectar el grupo "Gestión de Créditos" en `AdminSidebar` (icono `CreditCard`, clave
`creditos`, 5 enlaces sin truncamiento) y crear las rutas del Módulo 1 — Gestión de
Contratos — bajo `/admin/creditos`, con alta de cliente inline o selección existente,
formulario con mapas `vehiculo`/`condiciones`/`asignaciones`, dropdowns desde
`sys_admin_users` y validación de tipos number (Int64/Float). Cumple OVERRIDE #5.

## Code Patterns (Model Resilience)

- `src/components/AdminSidebar.tsx:32` — `openGroups` (`simuladores`, `config`),
  `toggleGroup`, `isActive(path)`, grupos colapsables `ChevronDown/ChevronRight`.
  `CreditCard` ya importado (línea 21). **NO alterar** `simuladores`/`config`.
- `src/app/admin/layout.tsx:26` — guard `ProtectedRoute allowedRoles={['admin','superadmin']}`.
  Las rutas heredan el guard; PROHIBIDO bypass de auth paralelo.
- `src/app/admin/config/page.tsx` — patrón CRUD cliente: `getDocs`, modal, `handleSave`,
  tabla, `loading`, iconos `lucide-react`.
- `src/context/AuthContext.tsx:126` — `useAuth()` provee `user`; el formulario envía
  `{ uid: user.uid, idToken: await user.getIdToken() }` al Server Action.
- `src/app/admin/creditos/actions.ts` (09-03) — `createCredito`, `updateCredito`,
  `softDeleteCredito`, `createClienteCredito`.
- `src/lib/firebase.ts` — `db` client-SDK (solo LECTURAS).

## Conventions

- **C4 heredado:** Burst Mitigation (submit `disabled` durante pending), Faraday Cage
  (trim + whitelist antes de invocar el action), tolerancia de lectura de `celular`
  legacy a 10 dígitos sin null-masking silencioso.
- Lecturas client-SDK permitidas; TODAS las escrituras vía Server Actions.
- Dropdowns de `uid_admin`/`uid_usuario`/`uid_inversor` leen `sys_admin_users`
  (client-SDK, permitido); mostrar `email`/`nombre` y guardar el `uid`.
- Estilo oscuro del panel (`bg-gray-900`, `border-gray-800`) consistente con `admin/config`.
